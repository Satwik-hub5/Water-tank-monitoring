# Water Tank Monitoring System 

## Overview
This project monitors the water levels in industrial tanks using ESP32 microcontroller and ultrasonic sensors. Data is sent over RS485 and visualized on a Node-RED dashboard.

## Features
- Real-time water level monitoring
- RS485 communication
- Node-RED dashboard visualization

## Hardware Used
- ESP32, as a controller
- Ultrasonic Sensor, to measure water levels
- RS485 communication protocols

## How to Run
1. Upload code to ESP32.
2. Setup RS485 modules.
3. Import Node-RED dashboard JSON.
4. Monitor tank levels.

## Future Improvements
1. Mobile app integration
2. Predictive maintenance, with cloud integration
